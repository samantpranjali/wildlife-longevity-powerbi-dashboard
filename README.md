Wildlife Longevity Intelligence Dashboard
Overview
This Power BI project analyzes wildlife lifespan data to identify trends across species and taxonomic classifications. The dashboard is designed to present clear, interactive insights into longevity patterns within the dataset.
Objective
The purpose of this project is to explore how lifespan varies among different animal groups and to compare these variations at both micro (species) and macro (taxon class) levels.
Key Metrics
Average Lifespan
Maximum Lifespan
Minimum Lifespan
Total Species Count
Dashboard Features
Interactive bar chart displaying lifespan by species common name
Comparative analysis of lifespan by taxon class
Gender-based lifespan comparison using a donut chart
Clean dark-themed layout with consistent color grading
